# Расчет индекса массы тела (ИМТ)

Программный комплекс с графическим интерфейсом для автоматизированного расчета индекса массы тела (ИМТ), ведения анонимизированного журнала измерений и выдачи медицинских рекомендаций ВОЗ.

---

## RU — Пользовательская документация по эксплуатации ИС

### 1. Краткое описание программы
Разработанный программный комплекс представляет собой специализированную систему на языке Python, оснащенную оконным графическим интерфейсом пользователя (GUI). Приложение позволяет в интерактивном режиме вычислять показатели здоровья на основе введенных пользователем веса (кг) и роста (см), выдавая соответствующие официальные медицинские рекомендации ВОЗ. 

Программа оснащена подсистемой администрирования, которая обеспечивает надежную сериализацию анонимизированных антропометрических журналов в формате CSV, а также реализует алгоритмы их регулярного резервного копирования и аварийного восстановления.

### Цели и задачи проекта
* **Разработка ПО:** Создание программы на языке Python с графическим интерфейсом для вычисления индекса массы тела (ИМТ) и автоматического подбора рекомендаций на основе антропометрических данных (вес в килограммах, рост в сантиметрах).
* **Система хранения и администрирования:** Разработка алгоритма анонимизированного логирования (с использованием уникальных UUID) в файлы CSV, а также процедур резервного копирования и восстановления данных.
* **Документирование:** Составление полного комплекта технической и пользовательской документации (Техническое задание, Руководство пользователя [README.md на русском и английском языках] и Регламент ТО) для фиксации в репозитории GitHub.
* **Верификация:** Составление тест-кейсов и проведение автоматизированного регрессионного тестирования ключевых модулей ИС на соответствие техническому заданию.

### Технологии
* **Python 3.8+** — основной язык программирования.
* **Tkinter** — построение графического интерфейса пользователя (GUI).
* **CSV** — формат структурированного хранения анонимизированных журналов измерений.
* **Shutil и OS** — модули сопровождения, бэкапа и прямой работы с файловой системой.
* **Unittest** — фреймворк автоматизированного тестирования работоспособности модулей.

### 2. Гайд по установке

#### Системные требования:
* **Операционная система:** Windows 10/11, macOS или дистрибутивы Linux.
* **Интерпретатор:** Среда выполнения Python версии 3.8 или выше.
* **Права доступа:** Разрешение операционной системы на чтение и запись файлов в целевую директорию проекта.

#### Пошаговый процесс установки:
1. Клонируйте репозиторий или скачайте исходные файлы проекта:
   ```bash
   git clone https://github.com
   cd bmi-calculator
   ```
2. Поместите файлы в общую рабочую папку на диске компьютера (рекомендуется использовать путь без кириллицы и пробелов в названиях, например: `C:\bmi_project\`).
3. Откройте терминал или командную строку в созданной директории с файлами.
4. Проверьте доступность интерпретатора Python в системе, выполнив команду:
   ```bash
   python --version
   ```
   *Дополнительная установка сторонних библиотек и пакетов не требуется, используются только встроенные модули.*

### 3. Руководство по использованию

#### Запуск программного комплекса:
Для инициализации графического интерфейса ИС выполните в терминале команду запуска главного пускового модуля:
```bash
python main.py
```

#### Интерактивный расчет в графическом интерфейсе (GUI):
1. В окне программы найдите поля ввода антропометрических параметров.
2. Введите числовые значения:
   * **Вес пользователя** — в килограммах (например: `70`).
   * **Рост пользователя** — в сантиметрах (например: `175`).
3. Нажмите кнопку **«Рассчитать»** — на панели мгновенно отобразится точное значение ИМТ, категория состояния веса по классификации ВОЗ и персональные рекомендации.
4. Нажмите кнопку **«Добавить в журнал»**, чтобы зафиксировать анонимизированную запись (ей автоматически присвоится UUID) в файл `data/anthropometric_journal.csv`.
5. Для создания ручной точки восстановления нажмите **«Резервная копия журнала»**. Копия запишется в папку `data/` со штампом даты и времени.
6. Для выгрузки текстовых результатов нажмите **«Экспорт отчёта»**.

#### Восстановление данных из резервной копии:
При случайном удалении, повреждении или потере рабочего журнала:
1. Перейдите в каталог `data/`.
2. Найдите самый свежий актуальный файл резервной копии вида `journal_backup_ГГГГММДД_ЧЧММСС.csv`.
3. Переименуйте его или скопируйте под именем `anthropometric_journal.csv` (заменив поврежденный файл).

### 4. Тестирование
Так как файл автоматизированных тестов `test_bmi_func.py` находится в корневом каталоге проекта, запуск комплексного регрессионного тестирования модулей на соответствие ТЗ выполняется прямой командой:
```bash
python -m unittest test_bmi_func.py -v
```
