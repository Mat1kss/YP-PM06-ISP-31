# Расчет индекса массы тела (ИМТ)

Программный комплекс с графическим интерфейсом для автоматизированного расчета индекса массы тела (ИМТ), ведения анонимизированного журнала измерений и выдачи медицинских рекомендаций ВОЗ.

##  Краткое описание

Приложение позволяет в интерактивном режиме вычислять показатели здоровья на основе введенных пользователем веса (кг) и роста (см). Программа оснащена подсистемой администрирования, которая обеспечивает надежное сохранение анонимизированных антропометрических журналов в формате CSV и реализует алгоритмы их резервного копирования и восстановления.

##  Технологии

* **Python 3.8+** — основной язык программирования.
* **Tkinter** — построение графического интерфейса пользователя (GUI).
* **CSV** — формат хранения анонимизированных журналов измерений.
* **Shutil и OS** — модули для резервного копирования и работы с файловой системой.
* **Unittest** — фреймворк автоматизированного тестирования.

##  Системные требования

* **Операционная система:** Windows 10/11, macOS или Linux.
* **Интерпретатор:** Python версии 3.8 или выше.
* **Права доступа:** разрешение на запись файлов в целевую директорию проекта.

##  Установка и запуск

Клонируйте репозиторий или скачайте исходные файлы:
   ```bash
   Git clone https://github.com/your-username/bmi-calculator.git
   Cd bmi-calculator
   ```

Убедитесь, что интерпретатор Python доступен в системе:
   ```bash
   Python –version
   ```

Запустите главный исполняемый модуль:
   ```bash
   Python main.py
   ```

Дополнительная установка сторонних библиотек не требуется.

##  Руководство по использованию

### Графический интерфейс (GUI)

1. Запустите программу командой `python main.py`.
2. Введите вес (в килограммах, например: `70`) и рост (в сантиметрах, например: `175`).
3. Нажмите кнопку **«Рассчитать»** — в панели результата отобразится ИМТ, категория по ВОЗ и рекомендации.
4. Нажмите **«Добавить в журнал»**, чтобы сохранить анонимизированную запись (с уникальным UUID) в файл `data/anthropometric_journal.csv`.
5. Для создания резервной копии нажмите **«Резервная копия журнала»**. Копия сохранится в папку `backups/` с меткой даты и времени.
6. Для экспорта текстового отчета нажмите **«Экспорт отчёта»**.

### Восстановление из резервной копии

При повреждении или удалении рабочего журнала:

1. Откройте папку `backups/`.
2. Найдите последний актуальный файл вида `journal_backup_ГГГГММДД_ЧЧММСС.csv`.
3. Скопируйте его в папку `data/` и переименуйте в `anthropometric_journal.csv`.
